## Changes

Adding a second attachment reproduced a debug desktop crash in GPUI's
accessibility tree: `Duplicate a11y node id`. Retry and Remove now have distinct
IDs and file-specific accessible names. Native two-file selection and recovery
subsequently completed without that crash.

Picker results are bound to the original Session and event-stream generation.
File opens use `NOFOLLOW`, `NONBLOCK` and `CLOEXEC`, followed by a regular-file
descriptor check. Draft attachment edits cannot mutate an in-flight, appended
or uncertain message; direct file drops also respect in-flight/session-switch
guards. Existing storage migrations and attachment validation are reused.
